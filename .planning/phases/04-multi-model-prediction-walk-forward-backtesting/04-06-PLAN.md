<objective>
Build the two zero-I/O orchestration modules that tie every prior plan's pure model/metrics/fold code together: `backtest.py` (per-fold walk-forward evaluation, PRED-04) and `engine.py` (`generate_forecast`, the single dispatch entry point every page calls, PRED-02/PRED-03).

Purpose: this is the composition layer -- `backtest.py` is the second half of PRED-04's no-lookahead guarantee (Plan 03 built the structural fold-generation half; this plan proves no model ever sees a test fold's own data during that fold's fit call). `engine.py` is the single place model/horizon input validation happens (V5, T-04-05) and the single place a Prophet-unavailable or any other failure degrades to a predictable status dict instead of crashing -- Plan 08's page code never talks to `sma_model`/`xgboost_model`/`prophet_model`/`backtest` directly, only to `engine.generate_forecast`.

Output: `src/prediction/backtest.py`, `src/prediction/engine.py`, plus three test files (backtest-specific leakage/Sharpe tests, engine-specific dispatch/validation tests, and a cross-model CI-invariant integration test run through the real `generate_forecast` call path) -- all green, zero network calls.
</objective>
