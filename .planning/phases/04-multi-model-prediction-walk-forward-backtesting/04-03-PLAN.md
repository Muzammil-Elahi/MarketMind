<objective>
Build the shared, zero-I/O walk-forward fold generator (`walk_forward.py`) and backtest-metrics module (`metrics.py`) every one of this phase's three model backtests and the orchestrating `backtest.py`/`engine.py` (Plan 06) depend on.

Purpose: `make_folds` is the single source of the no-lookahead-bias guarantee PRED-04 requires -- every model's backtest evaluation (Plans 04/05/06) calls this one function rather than each implementing its own fold-splitting logic, eliminating the exact class of off-by-one lookahead bug 04-RESEARCH.md's Anti-Patterns section warns against. `metrics.py` guarantees all three models are compared using identical RMSE/directional-accuracy/Sharpe formulas (D-06's apples-to-apples "Compare all models" requirement) and centralizes the asset-class-aware Sharpe annualization Pitfall 5 flags as an easy place to silently get wrong.

Output: `src/prediction/walk_forward.py`, `src/prediction/metrics.py`, plus two test files -- all green, zero network calls, including a D-11-style structural leakage smoke test for the fold generator.
</objective>
