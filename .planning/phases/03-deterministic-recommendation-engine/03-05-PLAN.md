<objective>
Build `src/recommendation/engine.py` -- the orchestrator that turns an already-assembled per-asset feature DataFrame plus an investor profile into a ranked, explainable, sub-score-transparent recommendation set: `score_universe` (the single scoring pipeline, REC-01/REC-02/REC-03) and `build_recommendations` (D-05's top-N-per-class grouping on top of it).

Purpose: this is the phase's central deliverable -- every other plan either feeds this module (Plans 01/02/04) or consumes it (Plans 06/07). `score_universe` is deliberately the ONE scoring function both the ranked-list page and the search/drill-in page call (REC-04's single-source-of-truth requirement), parameterized by `apply_hard_exclude` rather than duplicated.

Output: `src/recommendation/engine.py`, plus `tests/test_recommendation_engine.py` -- all green, zero network/LLM calls anywhere in the module or its tests.
</objective>
