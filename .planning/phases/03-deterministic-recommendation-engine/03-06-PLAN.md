<objective>
Build the Recommendations page (REC-01/REC-02/REC-03's user-facing surface): a `require_auth()`-gated, per-asset-class ranked shortlist showing each asset's composite score, sub-factor breakdown chart, and one-sentence explanation, with the persistent disclaimer banner and a "View Details" cross-navigation to the Search page (Plan 07).

Purpose: this is where a signed-in user actually sees the deterministic recommendation engine's output. The page is deliberately thin -- all scoring lives in `engine.py` (Plan 05), all fetching in `_universe_loader.py` (Plan 01), all charts/disclaimer in `components/` (Plan 04) -- this plan's only job is orchestration and rendering, mirroring `src/pages/profile.py`'s page-thin/module-thick split.

Output: `src/pages/recommendations.py` (`render_recommendations_page()`), not yet registered in `src/app.py` (Plan 08 does that once both new pages exist).
</objective>
